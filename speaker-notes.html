  21. Slide 222 min

    Toolkit 2: Attack patterns you will meet

    • Do not read every row. Pick the three that match what faculty already know, then point to the new ones: beacon, MFA fatigue and baseline poisoning.
    • Beacon: malware "calls home" at regular times. Regular timing is the clue, because people are not that regular.
    • Password spray: the attacker tries a few common passwords on many accounts, so no single account shows many failures.
    • MFA fatigue: the attacker sends many approval requests, hoping a tired user taps "approve".
    • Poisoning: the attacker changes the data the model learns from, so the model learns that bad is normal.
    • The letter shows which scenario uses the pattern. You do not need to remember every row. The key words slides near the end explain the terms.
  22. Slide 231.5 min
